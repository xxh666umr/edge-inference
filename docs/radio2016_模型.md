# RadioML 2016.10a 重训模型（部署版）

> 数据：RML2016.10a（Zenodo record 18397070，CC BY-NC-SA 4.0，仅学术/非商业用途，不随仓库分发）
> 训练脚本：`tools/train_radio2016.py`　　导出：`models/model.{h,c}`、`demo_sample.h`、`modrec_meta.json`
> 生成日期：2026-10-30

## 1. 数据集

| 项 | 值 |
|---|---|
| 类别 | 11 类：8PSK、AM-DSB、AM-SSB、BPSK、CPFSK、GFSK、PAM4、QAM16、QAM64、QPSK、WBFM |
| 样本 | 11 类 × 20 SNR × 1000 = **220,000** 条 |
| SNR | **-20 ~ +18 dB**（2 dB 步进，比旧 550 条子集的 -10~30 dB 更难） |
| 每条 | (2, 128) float32（I/Q 各 128 点） |
| 划分 | 按 (类, SNR) 分层 80/10/10：训练 176,000 / 验证 22,000 / 测试 22,000 |
| 下载 | Zenodo 18397070 的 `RML2016.10a.tar.bz2`（203 MB），解压得 `RML2016.10a_dict_optimized.pkl`（225 MB） |

## 2. 训练设置

- 模型不变（与 550 条版本同结构同参数量）：2×128 → conv(k7,s2,16) → pool2 → conv(k5,s2,32)
  → pool2 → 全局平均 → FC11，**3,195 参数**；
- 预处理：每条样本功率归一化（平均功率=1）；
- 数据增广：随机相位旋转、循环时移、幅度缩放（**不再额外加噪**——数据本身已覆盖 -20~18 dB，
  实测额外加噪会拉低精度约 2.6 pt）；
- 优化：AdamW(lr 2e-3, wd 1e-4)、cosine 退火、label smoothing 0.05、batch 512、
  **200 epochs**、最后 5 epoch 权重平均（SWA-lite）；
- 训练加速：数据与增广全部放在 GPU（RTX 4060）上向量化，200 epochs 约 3 分钟。

## 3. 结果（22,000 条测试集）

| 指标 | 浮点 | int8 | 掉点 |
|---|---|---|---|
| 全 SNR（-20~18 dB） | **52.34%** | **52.05%** | 0.28 pt |
| SNR ≥ -10 dB（16,500 条，与旧口径可比） | **66.53%** | **66.16%** | 0.37 pt |
| 高 SNR（0~18 dB） | 72~80% | 72~80% | — |

逐 SNR（int8）：-20dB 8.9%（≈随机）→ -10dB 19.1% → 0dB 72.7% → 6dB 79.6% → 18dB 80.0%。

逐类（int8）：AM-SSB 88.3%，QAM64 64.2%，AM-DSB 62.4%，CPFSK 61.2%，PAM4 60.5%，
GFSK 59.8%，BPSK 58.9%，QPSK 49.0%，8PSK 39.9%，WBFM 23.5%，**QAM16 5.0%**。

主要短板：
1. **QAM16 几乎全被误判为 QAM64**（16QAM 与 64QAM 的星座幅度层级在 128 点、8 倍过采样下区分度低）；
2. 8PSK 与被 QPSK 混淆；WBFM 与 AM-DSB 接近；
3. -12 dB 以下基本是随机水平（信息论上极难，任何小模型都如此）。

## 4. 与旧模型（550 条 2018 子集）的对比

| 模型 | 训练数据 | 在 2016 测试集 | 在 2018 子集（同域） |
|---|---|---|---|
| 旧 | RadioML 2018 子集 550 条 | **8.81%**（≈随机，跨域不迁移） | 58.55%（5 折 CV） |
| 新 | 2016.10a 220,000 条 | **52.34%**（全 SNR）/ 66.53%（≥-10） | — |

说明：旧模型是在 2018 子集上过拟合的小模型，**不能跨数据集迁移**；这也说明
“要部署到目标场景，必须用目标数据训练”，是本轮重训的直接动机。

## 5. 对 MCU 部署的影响

- 输入从 2×126 变成 2×128，卷积输出长度 60→61，MAC 数 +3%；
- 板载实测时延 **1,115,788 cycles = 15.50 ms**（与旧模型 15.46 ms 基本一致）；
- 模型参数/权重字节数完全不变（3,195 参数 / int8 3,136 B）。

## 6. 复现

```powershell
# 1) 下载数据（页面：https://zenodo.org/records/18397070 ，约 203 MB）
#    解压 RML2016.10a.tar.bz2 得到 RML2016.10a_dict_optimized.pkl，放到 data/ 下
# 2) 训练 + 量化 + 导出（GPU 约 3~5 分钟）
& $py tools\train_radio2016.py --epochs 200 --no-noise-aug
# 3) 对齐验证
& $py tests\test_model_parity.py
```

## 7. 后续改进方向

- 更强前端：I/Q 幅相特征、多尺度卷积、或直接对 128 点做多通道小卷积；
- 模型容量：c1/c2 = 24/48 可再 +0.5 pt，但板载时延翻倍（约 30 ms），性价比低；
- 类别不平衡问题：QAM16/QAM64 对做针对性增强或代价敏感损失；
- 换大芯片（H743/K210）后可上更复杂模型，届时精度可到 65%+（全 SNR）。
